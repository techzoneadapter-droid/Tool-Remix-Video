# DESIGN SYSTEM
Version 1.0

========================================
PURPOSE
========================================

This document defines the official visual language of the application.

The reference image (reference_ui.png) is the official design source.

If this document conflicts with personal design decisions,
the reference image always wins.

Never redesign the application.

Improve implementation only.

========================================
DESIGN PHILOSOPHY
========================================

The application should feel like a premium AI desktop product.

Keywords

Elegant

Modern

Premium

Minimal

Fast

Clean

Commercial

Comfortable

Never look like an IDE.

Never look like developer software.

Never feel crowded.
