# UI Reference

The file:

reference_ui.png

is the official design reference.

Every UI implementation must visually match this image.

When implementing UI:

- Continuously compare with reference_ui.png.
- Match spacing.
- Match padding.
- Match colors.
- Match border radius.
- Match shadows.
- Match icon sizes.
- Match typography.
- Match alignment.
- Match proportions.

Never redesign.

Never reinterpret.

Always replicate.

Only improve responsiveness and code quality.

The reference image has higher priority than your own design decisions.
